# Frontend Mentor - Loopstudios landing page

![Design preview for the Loopstudios landing page coding challenge](preview.jpg)

## Welcome! 👋

[Frontend Mentor](https://www.frontendmentor.io) challenges helped me improve my coding skills by building realistic projects.

**To do this challenge I used HTML and CSS.**

## The goal of this challenge

To make the website as close as the pre-defined design, both desktop and mobile version. 

Also the users should be able to:

- View the optimal layout for the site depending on their device's screen size
- See hover states for all interactive elements on the page

## What materials I used

All the assets can be found in the `/images` folder and they've been optimized.

For the fonts I used [Alata](https://fonts.google.com/specimen/Alata) and [Josefin Sans](https://fonts.google.com/specimen/Josefin+Sans)


## Building the project

After looking carefully over the design and planning how I'll tackle the project, I began laying down the structure of my content with HTML.

Then I continued by writing the styles using CSS. Starting out with root elements, and then moving onto the actual styles - having in mind the mobile-first design for better overall construction. 

I tried implementing utility classes to apply consistent global styles across multiple components, avoiding code duplication.
